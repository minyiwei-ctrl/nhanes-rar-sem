# Rest–activity rhythm dimensions, biological ageing, depressive symptoms and cognition — NHANES 2011–2014

Analysis code for:

> Min Y, Liu J. *Rest-activity rhythm dimensions show age-dependent
> associations with biological aging, depressive symptoms, and cognition in
> US adults.* (submitted)

Seven-day wrist accelerometry from 8,955 US adults is summarised by three
non-parametric rest–activity metrics — relative amplitude, interdaily
stability and intradaily variability — which are related, in complex-survey
structural equation models, to Klemera–Doubal biological-age advancement and
the systemic immune-inflammation index in parallel, and through them to
depressive symptoms and cognitive function, separately below and at or above
age 60.

## What is here

This repository holds the code only. Every table and figure in the article
and its Supplementary Information is rebuilt by running the pipeline; none
is stored here, and nothing participant-level is either. All data are
public NHANES releases.

| path | contents |
|---|---|
| `scripts/` | the pipeline: numbered stages (Jupyter notebooks and one R script) that run in order, the library modules they import, and the checkers that run after them. `scripts/README.md` lists every file with its inputs and outputs |
| `scripts/9_mplus_models/` | the 51 Mplus input files, one per model, the generator for the templated ones, and `run_all.sh`, which runs them |
| `VARIABLES.md` | every variable in the Mplus data files, with the script that creates it and its definition (generated by `scripts/variable_dictionary.py`) |
| `data/README.md` | the NHANES files to download, and where the pipeline writes its own files |
| `requirements.txt`, `R-requirements.md` | the Python and R environments |
| `CITATION.cff`, `LICENSE` | how to cite; MIT licence |

## Reproducing the results

1. **Data.** Download the NHANES 2011–2012 and 2013–2014 files listed in
   `data/README.md` into `data/raw/`.
2. **Environment.** Python ≥ 3.10 (3.12 was used) with the packages in
   `requirements.txt`; R ≥ 4.2 with `BioAge`, `dplyr`, `readr`, `tibble`
   (`remotes::install_github("dayoonkwon/BioAge")`); Mplus 9 for the
   structural models.
3. **Run the stages in order** from `scripts/` — `1` … `9`, then the Mplus
   models (`cd scripts/9_mplus_models && bash run_all.sh`), then `10` … `18`.
   Stage `5` reads the minute-level accelerometry (about 26 GB as CSV) and
   takes hours; every other stage runs in minutes. Tables are written to
   `result/`, figures and their source data to `figure/`, and stage `10`
   finishes by running the checkers and writing the caption and
   display-item documents.
4. **Check.** `python scripts/verify_figures.py` (figure specification and
   source data), `display_map.py`, `variable_dictionary.py` and
   `captions.py` each exit non-zero on a defect. `verify_citations.py`
   checks the manuscript drafts against the display items and skips itself
   where the drafts are not present.

Every notebook locates the project root from its own position, so the
repository can be cloned anywhere; set `NHANES_SEM_ROOT` if Jupyter is
started outside it.

## Design notes

- **Model selection is guarded.** The primary models are chosen by an
  `Analysis` label carried on every parsed row, never by file order; a
  sensitivity model cannot reach a main table or figure without raising.
- **Every display item is checked against its own source.** Captions are
  assembled from each item's Notes or legend sheet; the citation checker
  reads the manuscript body and fails on an uncited or non-existent item.
- **Display conventions live in one place.** `nature_palette.py` holds the
  colour per rhythm metric, the age-group labels and the number format;
  nothing is re-implemented in a notebook.
- **The accelerometry numerics are validated against known answers.**
  `_validate_rar_core.py` asserts `rar_core.py` on synthetic profiles before
  the pipeline touches the minute-level files.
